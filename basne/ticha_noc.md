# 静夜思 · Tichá noc · Li Po (李白, 701–762)

```
床前明月光    chuáng qián míng yuè guāng
疑是地上霜    yí shì dì shàng shuāng
举头望明月    jǔ tóu wàng míng yuè
低头思故乡    dī tóu sī gù xiāng
```

Doslovně, znak po znaku:

| znak | pinyin | význam |
|---|---|---|
| 床 | chuáng | postel |
| 前 | qián | před |
| 明 | míng | jasný |
| 月 | yuè | měsíc |
| 光 | guāng | světlo |
| 疑 | yí | zdát se, tušit |
| 是 | shì | být |
| 地 | dì | zem |
| 上 | shàng | na |
| 霜 | shuāng | jinovatka |
| 举 | jǔ | zvednout |
| 头 | tóu | hlava |
| 望 | wàng | hledět |
| 低 | dī | sklonit |
| 思 | sī | myslet, stýskat |
| 故 | gù | starý, rodný |
| 乡 | xiāng | kraj, domov |

Pracovní překlad (nahraď svým oblíbeným, Mathesiův je od roku 2023 volný):

```
Před postelí svit měsíce,
snad jinovatka na zemi.
Zvednu hlavu, hledím na měsíc,
skloním hlavu, stýská se mi po domově.
```

Dvacet znaků, čtyři verše po pěti. Znak 明月 (jasný měsíc) se opakuje
ve verši 1 a 3, 头 (hlava) ve verši 3 a 4: to jsou první kandidáti na
spojení, až přijde na řadu BPE.
